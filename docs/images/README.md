# Documentation screenshots

Updated for **Link Card v2.5.1**. These JPEG screenshots were captured from an offline demo using the production SwiftUI `ContentView` with an injected sample model. The demo blocked all HTTP requests and did not read real credentials.

- `overview-zh.jpg`: signed-in account, request selection, and history statuses.
- `login-zh.jpg`: browser authorization link and a fictional phrase.
- `create-en.jpg`: responsive English creation form with automatically generated context.
- `create-review-en.jpg`: review dialog; the submission button was not clicked.
- `card-details-zh.jpg`: fictional virtual card fields and billing address.
- `cancel-confirmation-zh.jpg`: cancellation dialog; the cancellation button was not clicked.

All accounts, merchants, IDs, authorization phrases, addresses, and card details in these images are examples. They are not real payment credentials. No purchase or cancellation was performed to make these screenshots.

- `approve-zh.jpg`: pending-request review and the official Link approval link.
- `responsive-narrow-zh.jpg`: 540-point window with single-column fields.
- `responsive-narrow-bottom-zh.jpg`: expiry, generated context, and creation button reached by scrolling.
