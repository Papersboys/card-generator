从请求到结账

三步，拿到可用的卡信息。

    创建请求

    登录 Link，选择付款方式，填写商家和实际结账金额。USD 以美分填写：1500 = $15。

  2. 2

    在 Link 中批准

    打开批准链接，亲自核对并确认。你可以在待批准页重新找到之前的请求。

  3. 3

    复制卡信息结账

    返回 App 查看卡号、CVC、有效期和账单地址，复制到商家付款页完成结账。

FAQ

下载前，你可能想知道。

支持哪些 Mac？需要安装其他工具吗？

支持 Apple Silicon（M 系列芯片）及 macOS 13 或更新版本。下载 ZIP、解压，将 LinkCard.app 拖到 Applications 即可。无需安装 Node.js、npm 或 link-cli。

第一次打开被 macOS 阻止怎么办？

当前版本使用 ad-hoc 签名，尚未经过 Apple 公证。确认从本项目的 GitHub Release 下载后，尝试打开，再到系统设置 → 隐私与安全性，选择“仍要打开”。

可以自动更新吗？

v2.6.0 起默认每天检查新版，也可在 App 内手动检查。确认后下载、安装并重启；更新清单和安装包都会校验签名。旧版本需要先手动升级一次。

支持哪些币种？

默认 USD，金额以美分填写，最低 50（$0.50）。其他币种使用三位代码及各自最小单位。Link 未公开完整清单，实际支持情况以 API 返回为准；App 不进行汇率换算。

这是 Link 官方产品吗？会存储我的卡信息吗？

这是独立开源项目，与 Link 或 Stripe 无隶属关系。App 不经过开发者服务器，登录凭证保存在本机 Keychain，卡信息仅在内存中显示。你可以随时退出登录，清除本 App 的凭证。
